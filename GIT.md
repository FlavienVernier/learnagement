# Git

- main → Production / last stable ;
- prerelease → Préparation d'une version ;
- dev → Intégration des développements ;
- feature/ → nouvelles fonctionnalités ;
- enhancement/ → Amélioration d'une fonctionnalité existante (sans en créer une nouvelle) ;
- bugfix/ → corrections de bugs ordinaires ;
- hotfix/ → corrections urgentes en production (clone de prerelease) ;
- refactor/ → amélioration du code sans changement fonctionnel ;
- update/ → mises à jour (bibliothèques, documentation, configuration) ;
- chore/ → Tâches de maintenance diverses (nettoyage, configuration, CI/CD...)
